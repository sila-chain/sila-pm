# SIP-4844 Meetings

## Purpose
SIP-4844 introduces a new kind of transaction type to Sila which accepts "blobs" of data to be persisted in the beacon node for a short period of time. These changes are forwards compatible with Sila's scaling roadmap, and blobs are small enough to keep disk use manageable.
